**Completion Date:** September 2021

**Tools:** Java, FXML, CSS, JavaFX, Spring Boot, MongoDB.

- Developed a desktop application for posting, assigning, and managing contract work.
- Built a Spring Boot back-end server to improve maintainability and scalability.
- Designed an intuitive user interface with both light and dark themes.

The source code is available on [GitHub](https://github.com/amritoo/deyal).
