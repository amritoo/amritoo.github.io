**Completion Date:** October 2020

**Tools:** Java, XML, Android Studio, Firebase, Realtime Database, Bluetooth Classic.

- Developed an Android application that unifies online and offline messaging in a single platform.
- Implemented offline messaging over Bluetooth for short-range communication.
- Added features such as text and image messaging, and adding and blocking contacts.

The source code is available on [GitHub](https://github.com/amritoo/JAM).
