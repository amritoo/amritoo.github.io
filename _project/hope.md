**Completion Date:** November 2022

**Tools:** HTML, CSS, JavaScript, Java, MySQL, Vue.js, Spring Boot.

- Developed a MOOC platform that mirrors traditional academic roles and functionalities.
- Implemented features identified through a user survey, including multiple quiz question types, learner rankings, and multimedia support.

The source code is available on [GitHub](https://github.com/amritoo/HOPE).
